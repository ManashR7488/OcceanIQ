# Ocean Background Video

## Instructions

Place your ocean background video file in this directory with the name `ocean-background.mp4`.

## Recommended Video Specifications

- **Format**: MP4 (H.264 codec)
- **Resolution**: 1920x1080 or higher (Full HD or 4K)
- **Duration**: 10-30 seconds (the video will loop automatically)
- **File size**: Keep under 5MB for faster loading
- **Content**: Underwater ocean scenes, waves, coral reefs, or marine life

## Free Video Sources

You can download free ocean videos from:

- **Pexels Videos**: https://www.pexels.com/search/videos/ocean/
- **Pixabay**: https://pixabay.com/videos/search/ocean/
- **Videvo**: https://www.videvo.net/free-stock-video/ocean/
- **Coverr**: https://coverr.co/s/ocean

## Note

If no video file is present, the home page will display a beautiful gradient background as a fallback. The page will work perfectly without the video, but adding one enhances the visual experience.

## Example Search Terms

When searching for videos, try these terms:
- "ocean underwater"
- "ocean waves"
- "underwater coral"
- "deep blue ocean"
- "marine life"
- "ocean surface"
